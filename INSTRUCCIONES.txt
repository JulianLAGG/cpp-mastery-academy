1. CONTEXTO DE LA APLICACION
--------------------------------------------------------------------------------
C++ Mastery Academy es una plataforma educativa interactiva de escritorio/web
local diseñada para aprender a programar en C++ (estándar C++17) desde cero
absoluto hasta un nivel intermedio sólido.

A diferencia de un curso estático, la aplicación integra el compilador real
`g++` instalado en tu sistema Linux. Esto permite escribir, compilar, ejecutar
y depurar código C++ real directamente desde el navegador, además de validar
automáticamente los ejercicios prácticos con casos de prueba reales.

Características principales:
- Curso guiado estructurado en 8 Módulos y 17 Lecciones progresivas:
  * Módulo 1: Primeros pasos (main, iostream, std::cout, variables, std::cin)
  * Módulo 2: Control de flujo (if/else, operadores lógicos, bucles for/while)
  * Módulo 3: Funciones, sobrecarga y paso por Valor vs. Referencia (&)
  * Módulo 4: Arreglos dinámicos (std::vector) y manejo de std::string
  * Módulo 5: Punteros (*), direcciones (&), nullptr y Smart Pointers (unique_ptr)
  * Módulo 6: Programación Orientada a Objetos (class, constructores, herencia,
              polimorfismo con virtual/override)
  * Módulo 7: Plantillas (templates) y librería estándar STL (std::map, std::sort,
              expresiones lambda)
  * Módulo 8: Manejo de excepciones (try/catch/throw), archivos (<fstream>) y
              Proyecto Final Integrador (Sistema de Inventario POO + STL).
- Editor de código C++ integrado con números de línea, soporte de tabulación y
  atajo rápido (Ctrl + Enter) para compilar y ejecutar.
- Caja de Entrada Estándar (stdin) para probar programas que leen datos con
  `std::cin` o `std::getline`.
- Protección automática contra bucles infinitos (límite de 4 segundos por
  ejecución) y reporte claro de errores de compilación o memoria (SIGSEGV).
- Cuestionarios interactivos (Quizzes) y Retos Prácticos autocorregidos en cada
  lección, con pistas y solución de referencia.
- Sistema de progreso y gamificación (puntos XP y rangos) guardado
  automáticamente en el navegador (localStorage).
- "Laboratorio Libre" (Playground) con plantillas rápidas para experimentar.
- "Hoja de Referencia" (Cheatsheet) con la sintaxis esencial de C++17.


2. REQUISITOS DEL SISTEMA
--------------------------------------------------------------------------------
- Node.js (v16 o superior)
- Compilador g++ (GCC C++) instalado en el sistema.
  Puedes verificar ambos en tu terminal con:
    node -v
    g++ --version
- No requiere conexión a internet ni instalación de paquetes externos (usa los
  módulos nativos de Node.js para máxima velocidad y cero dependencias rotas).


3. COMO INICIAR LA APLICACION
--------------------------------------------------------------------------------
Paso 1: Abre una terminal y entra en la carpeta del proyecto:

    cd /home/wachinex/Documentos/appAgy

Paso 2: Inicia el servidor con cualquiera de estos dos comandos:

    npm start
    (o bien: node server.js)

Paso 3: Verás en la terminal el mensaje:
    "🚀 C++ Mastery Academy corriendo en: http://localhost:3000"

Paso 4: Abre tu navegador web y entra en:

    http://localhost:3000

(Nota: Si el puerto 3000 estuviera ocupado por otro programa, puedes iniciarla
en otro puerto ejecutando: PORT=4000 npm start)

Para detener el servidor en cualquier momento, presiona `Ctrl + C` en la
terminal donde lo hayas iniciado.


4. COMO EJECUTAR LAS PRUEBAS AUTOMATICAS (OPCIONAL)
--------------------------------------------------------------------------------
Si deseas comprobar que el compilador `g++` y las 17 lecciones del curso
funcionan correctamente desde la terminal, ejecuta:

    npm test
