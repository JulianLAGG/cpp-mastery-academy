1. CONTEXTO DE LA APLICACION
--------------------------------------------------------------------------------
C++ Mastery Academy es una plataforma educativa interactiva local diseñada para
aprender a programar en C++ (estándar C++17) desde cero absoluto hasta un nivel
intermedio sólido, con una interfaz inspirada en Zed IDE (Gruvbox Dark).

A diferencia de un curso estático, la aplicación integra el compilador real
`g++` instalado en tu sistema (Linux o Windows). Esto permite escribir,
compilar, ejecutar y depurar código C++ real directamente desde el navegador,
además de validar automáticamente los ejercicios prácticos con casos de prueba.

Características principales:
- Curso guiado estructurado en 8 Módulos y 17 Lecciones progresivas:
  * Módulo 1: Primeros pasos (main, iostream, std::cout, variables, std::cin)
  * Módulo 2: Control de flujo (if/else, operadores lógicos, bucles for/while)
  * Módulo 3: Funciones, sobrecarga y paso por Valor vs. Referencia (&)
  * Módulo 4: Arreglos dinámicos (std::vector) y manejo de std::string
  * Módulo 5: Punteros (*), direcciones (&), nullptr y Smart Pointers (unique_ptr)
  * Módulo 6: Programación Orientada a Objetos (class, constructores, herencia,
              polimorfismo con virtual/override)
  * Módulo 7: Plantillas (templates) y librería estándar STL (std::map, std::sort,
              expresiones lambda)
  * Módulo 8: Manejo de excepciones (try/catch/throw), archivos (<fstream>) y
              Proyecto Final Integrador (Sistema de Inventario POO + STL).
- Editor de código C++ con resaltado de sintaxis Gruvbox Dark en vivo,
  auto-cierre de llaves/paréntesis, auto-indentación inteligente y atajos
  rápidos (Ctrl + Enter para ejecutar, Ctrl + Shift + Enter para verificar).
- Caja de Entrada Estándar (stdin) para probar programas que leen datos con
  `std::cin` o `std::getline`.
- Protección automática contra bucles infinitos (límite de 4 segundos por
  ejecución).
- Cuestionarios interactivos (Quizzes) y Retos Prácticos autocorregidos en cada
  lección, con pistas y solución de referencia.
- Sistema de progreso y gamificación (puntos XP y rangos) guardado
  automáticamente en el navegador (localStorage).
- "Laboratorio Libre" (Playground) con plantillas rápidas para experimentar.
- "Referencia Rápida" (Cheatsheet) con buscador y copia rápida de sintaxis C++17.


2. REQUISITOS DEL SISTEMA (LINUX Y WINDOWS)
--------------------------------------------------------------------------------
- Node.js (v16 o superior)
- Compilador g++ (GCC C++) instalado y disponible en el PATH del sistema.
- No requiere conexión a internet ni ejecutar `npm install` (usa únicamente los
  módulos nativos de Node.js para máxima velocidad y cero dependencias rotas).

Puedes verificar que ambos están listos en tu terminal (Bash, PowerShell o CMD):
    node -v
    g++ --version


3. INSTALACION Y EJECUCION EN LINUX
--------------------------------------------------------------------------------
Paso 1: Instalar Node.js y g++ (si aún no los tienes):
  * Ubuntu / Debian / Mint:
      sudo apt update && sudo apt install -y nodejs npm build-essential g++ git
  * Arch Linux / Manjaro:
      sudo pacman -S --needed nodejs npm gcc git
  * Fedora:
      sudo dnf install -y nodejs npm gcc-c++ git

Paso 2: Entrar en la carpeta del proyecto e iniciar el servidor:
      cd cpp-mastery-academy
      npm start
      (o bien: node server.js)

Paso 3: Abrir el navegador en:
      http://localhost:3000


4. INSTALACION Y EJECUCION EN WINDOWS (10 / 11)
--------------------------------------------------------------------------------
Paso 1: Instalar Node.js
  Descarga el instalador LTS desde https://nodejs.org/ o ejecuta en PowerShell:
      winget install OpenJS.NodeJS.LTS

Paso 2: Instalar el compilador g++ (MinGW-w64)
  * Opción A (Rápida por PowerShell con winget):
      winget install BrechtSanders.WinLibs.POSIX.UCRT
    (Cierra y vuelve a abrir PowerShell al terminar).

  * Opción B (Mediante MSYS2 - https://www.msys2.org/):
    1. Instala MSYS2 y en su terminal ejecuta:
         pacman -S --needed mingw-w64-ucrt-x86_64-gcc
    2. Añade la carpeta `C:\msys64\ucrt64\bin` a la variable `Path` en las
       "Variables de entorno del sistema" de Windows.

Paso 3: Verificar en una nueva ventana de PowerShell o CMD:
      node -v
      g++ --version

Paso 4: Iniciar la aplicación en PowerShell o CMD:
      cd cpp-mastery-academy
      npm start
      (o bien: node server.js)

Paso 5: Abrir el navegador en:
      http://localhost:3000

(Nota: Si el puerto 3000 estuviera ocupado:
 - En Linux: PORT=4000 npm start
 - En Windows PowerShell: $env:PORT=4000; npm start
 - En Windows CMD: set PORT=4000 && npm start)

Para detener el servidor en cualquier momento, presiona `Ctrl + C` en la
terminal donde lo hayas iniciado.


5. COMO EJECUTAR LAS PRUEBAS AUTOMATICAS (OPCIONAL)
--------------------------------------------------------------------------------
Si deseas comprobar que el compilador `g++` y las 17 lecciones del curso
funcionan correctamente desde la terminal (en Linux o Windows), ejecuta:

    npm test
